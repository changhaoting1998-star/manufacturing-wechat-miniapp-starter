# Security policy

Please report vulnerabilities through GitHub's private security advisory flow.

Do not include real employee records, attendance locations, payroll amounts, signatures, WeChat identifiers, access tokens, private keys, Mini Program AppIDs, CloudBase environment IDs, internal URLs, or screenshots from a production system.

This starter uses synthetic data and an in-memory adapter. Before production use, add platform authentication, server-side authorization, encrypted storage, retention rules, audit export, rate limits, monitoring, backups, and incident response procedures.
